# 外観自動検査機シミュレータ

## 概要
製造現場の画像検査自動機の動作をArduinoとWokwiでシミュレートしたものです。
前職での外観検査自動機の運用経験をもとに設計しました。

## 動作確認
WokwiのURL：https://wokwi.com/projects/466100946370795521

## 動作の流れ
製品の個数入力 → 供給部（センサー検知）→ 切出部（製品投入） → 爪搬送（製品搬送） → 検査部（画像検査で寸法・傷判定）→ 良品/不良排出 → 集計表示

## 想定製品・検査条件
検査対象：金属部品  
検査項目：ネジ径（1箇所  
公差設定：上限10.05mm / 下限9.95mm  
※本シミュレーションで使っている製品は架空の製品です

## 機能
- センサーによるワーク検知
- 公差設定と計測値による寸法判定（計測値は公差範囲付近でランダム自動生成）
- 傷判定（画像検査の代替として一定確率でNG判定）
- OK/NGのLED表示
- 集計・不良率表示
